# Higgsfield商品レビュー動画(手動運用ランブック)

Higgsfield(https://higgsfield.ai)の**Marketing Studio**機能を使い、商品の販売ページURLから「AIキャラクターが実際にその商品を持って紹介しているレビュー動画」を作るための手順書です。

他のツール(`note-teaser-generator`・`edu-material-generator`)と違い、**このツールにはコード(自動化スクリプト)がありません。** Higgsfieldに公開APIが存在しないため、GitHub Issue起票→GitHub Actions自動実行、という無人運用の仕組みには組み込めず、**毎回ブラウザで手動操作する**運用になります。

## 前提条件

- Higgsfieldのアカウントとサブスクリプション登録(https://higgsfield.ai/pricing)
  - Marketing Studio自体はどのプランでも使えるが、動画1本ごとにクレジットを消費する
  - 目安: Kling 3.0程度の標準品質なら1本あたり約$0.6〜1、Sora 2/Veo 3.1のような高品質モデルを選ぶと1本あたり約$4〜11
- レビューしたい商品の販売ページURL(Amazon等のアフィリエイトリンクでも可)

## 手順

1. Higgsfieldにログインし、**Marketing Studio**を開く
2. 商品の販売ページURLを貼り付ける(AIが商品名・説明・画像を自動抽出する)
3. `prompts/`配下の商品ごとのプロンプトファイルの内容を、追加指示欄にコピペする(クリエイティブディレクション・キャラクター設定・台本の要点を含む)
4. クリエイティブディレクションを選択する(UGCスタイル/CGIコマーシャル/シネマティック/Wild Card自動演出、の4択。商品や訴求内容に応じて選ぶ。目安は各プロンプトファイルに記載)
5. 生成を実行し、完成した動画をダウンロードする
6. 実際のSNS投稿は人間が最終確認の上で手動投稿する(このリポジトリの他ツールと同じ方針で、全自動投稿は行わない)

## プロンプトファイルの追加

商品ごとに `prompts/<商品名>.md` として保存していく。新しい商品を追加する際は、次の項目を含める:

- 商品情報(商品名・カテゴリ・特徴・価格帯・ターゲット層)
- クリエイティブディレクションの推奨(UGC/CGI/シネマティック/Wild Cardのどれが合うか)
- キャラクター設定(年齢層・雰囲気・トーン)
- 台本の要点(フック→使用シーン→感想→CTAの流れ)

## 参考

- Higgsfield公式サイト: https://higgsfield.ai
- Marketing Studio: 商品URLを渡すだけで商品名・説明・画像を自動抽出し、テンプレートに沿った広告動画を生成する機能(公開APIはなし。ブラウザUI操作のみ対応)
