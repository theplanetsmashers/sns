# 暗黙知インタビューボット(MVP)

製造業の管理職・ベテラン技能者が持つ暗黙知を対話形式で引き出し、1回のインタビューから

- 社内向け技術継承マニュアル(PFMEA的な留意点込み)
- 研修用ケーススタディ(判断プロセスを追体験できる形式)
- note/ブログ用の一般公開記事

の3種類を自動生成するMVPです。`threads-post-generator` と同じく、Node.jsからClaude APIを直接呼び出すシンプルな構成にしています。

## セットアップ

1. `ANTHROPIC_API_KEY` を環境変数に設定する(claude.aiのサブスクとは別課金なので注意)
   ```
   export ANTHROPIC_API_KEY=sk-ant-xxxx
   ```
2. このディレクトリで依存関係は不要(Node.js 18+ の標準 `fetch` のみ使用)

## 使い方

### 1. インタビューを実施する

```
npm run interview
```

固定テンプレート(`questions.json`、8カテゴリ)に沿って質問が表示されるので、ターミナルに回答を入力します(複数行OK、空行で入力終了)。回答が抽象的だとClaudeが深掘り質問を1つ追加し、その場で暗黙知ポイントを要約します。

終了すると `sessions/` 配下にインタビュー記録がJSONで保存されます。

### 2. アウトプットを生成する

```
npm run outputs -- sessions/2026-XX-XXTXX-XX-XX-XXXZ_topic.json
```

`outputs/<セッション名>/` 配下に `manual.md`(マニュアル)、`case-study.md`(研修ケース)、`article.md`(note/ブログ記事)の3ファイルが生成されます。

## ファイル構成

- `questions.json` — インタビューの固定質問テンプレート(8カテゴリ: 背景・役割/異常検知のきっかけ/五感的な手がかり/意思決定プロセス/失敗・ヒヤリハット/例外対応/後進への伝え方/継承したい想い)
- `interview.js` — 「質問→回答→深掘り判定→要約」のループを回すインタビューCLI
- `generate-outputs.js` — セッション記録から3種類のアウトプットを生成するスクリプト
- `sessions/` — インタビュー記録(gitignore対象。個人情報・社外秘の可能性があるためコミットしない)
- `outputs/` — 生成されたマニュアル/ケース/記事(同上、gitignore対象)

## MVPとしての検証ステップ

1. まず自分自身の別のエピソード(例: 係長時代の別の判断場面など)で一度インタビューを回し、質問テンプレートと深掘り判定の精度を確認する
2. 精度に問題がなければ、他の製造業管理職に試してもらい、生成物の実用性(マニュアルとして使えるか、記事として公開できるか)を検証する

## 今後の拡張ポイント(MVP以降)

- インタビュー記録の保存先をGoogle Drive(ペルソナ・体験フォルダ構造)に変更し、複数人・複数セッションを横断管理できるようにする
- 個人向け(退職前ベテラン向け月額ツール)/法人向け(人事・技能伝承部門への導入、インタビュー代行込み)でプラン分岐
- 既存note読者向けに「あなたの経験を記事にしませんか」という追加サービスとして提供する導線を用意する
