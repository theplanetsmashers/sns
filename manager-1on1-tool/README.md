# 1on1支援ツール(フェーズ3)

「新任管理職になったが、1on1で何を話せばいいか分からない」という悩みを解決するためのツールです。
部下プロフィールを登録しておくと、Claude APIが1on1前のアジェンダ案を提案し、1on1後は生のメモから要点・判断基準・次回フォローを抽出して記録します。複数回の記録が溜まると、評価面談や異動判断の材料になる傾向サマリーも生成できます。

## 設計のポイント

- **直属部下と委任先チームリーダーでテンプレートを分ける** — 直属部下には成長・意思決定の拠り所を、委任先チームリーダーには委任範囲の進捗と判断基準のズレ確認を重視した観点でアジェンダを作ります。
- **感想ではなく判断基準を記録する** — 1on1後の記録では「良い感じだった」のような感想ではなく、「何を根拠にどう判断したか」を`judgmentCriteria`として言語化する設計にしています。属人化した勘ではなく、原理原則に基づいた振り返りを積み上げることが目的です。

使い方は2通りあります。

- **A. PCでローカル起動** — 動作確認用。`npm start` してブラウザで開く
- **B. ホスティングしてスマホから使う(推奨)** — 常時起動するURLを持ち、スマホのブラウザから直接開ける

---

## A. PCでローカル起動

```bash
cd manager-1on1-tool
ANTHROPIC_API_KEY=sk-ant-xxxx npm start
```

ブラウザで `http://127.0.0.1:3100` を開きます。

環境変数:

- `ANTHROPIC_API_KEY`(必須): Claude APIキー
- `PORT`(任意): 待受ポート。デフォルト `3100`
- `HOST`(任意): 待受ホスト。デフォルト `127.0.0.1`(自分のPC以外からアクセスされないようにするため)
- `APP_USERNAME` / `APP_PASSWORD`(任意): 設定するとBasic認証がかかる。ローカルのみで使う分には未設定でよい

---

## B. ホスティングしてスマホから使う(推奨)

部下の氏名や1on1の内容という機微な個人情報を扱うツールなので、**外部に公開する場合は認証を必ず設定します**。GitHubはコードの置き場所・自動デプロイの起点として使うだけで、利用者(自分や将来の利用者)がGitHubを直接操作したり、GitHubアカウントを持っている必要は一切ありません。ブラウザでURLを開いてID・パスワードを入力するだけです。

以下はRender(無料枠あり・GitHub連携で自動デプロイできるホスティングサービス)を使う場合の手順です。

1. [Render](https://render.com/)にサインアップし、GitHubアカウントと連携する
2. 「New +」→「Web Service」を選び、このリポジトリ(`theplanetsmashers/sns`)を選択する
3. 設定:
   - **Root Directory**: `manager-1on1-tool`
   - **Runtime**: Node
   - **Build Command**: (空欄でよい。依存パッケージがないため)
   - **Start Command**: `npm start`
4. 環境変数(Environment)に以下を追加する
   - `ANTHROPIC_API_KEY`: Claude APIキー
   - `HOST`: `0.0.0.0`(ホスティング環境では必須。これがないと外部からアクセスできない)
   - `APP_USERNAME` / `APP_PASSWORD`: 自分で決めたIDとパスワード(**この2つを設定しないと誰でもアクセスできてしまうので必ず設定する**)
   - `PORT`は設定不要(Render側が自動で割り当てる)
5. デプロイが完了すると `https://xxxxx.onrender.com` のようなURLが発行される。これをスマホのブラウザで開き、設定したID・パスワードを入力すればそのまま使える(ホーム画面に追加すればアプリのように使える)

コードを更新して`main`ブランチにpushすると、Renderが自動で再デプロイする。他のホスティングサービス(Railway, Fly.ioなど)でも同様の手順(Root Directory指定・Start Command `npm start`・上記の環境変数設定)で動く。

無料プランは一定時間アクセスがないとスリープし、次回アクセス時に起動まで数十秒かかることがある。常時起動させたい場合は有料プランへの切り替えが必要になる。

## 画面構成

1. **部下管理** — 名前・役割・経験年数・関係(直属部下/委任先チームリーダー)を登録
2. **1on1準備** — 対象と直近の業務状況を入力すると、優先度順のアジェンダ案(項目・理由・問いかけ例)を生成
3. **1on1後記録** — 1on1メモを貼り付けると、要点・判断基準・次回フォローをAIが抽出して記録
4. **履歴・傾向** — 対象を選ぶと過去の記録一覧と、複数回の記録から見える変化の傾向サマリーを生成

## ファイル構成

- `lib/generate.js` — Claude APIでアジェンダ生成・要点抽出・傾向分析を行う共通処理
- `lib/store.js` — 部下プロフィール・1on1ログの読み書き共通処理
- `server.js` — APIサーバー本体(Node標準ライブラリのみ、依存パッケージなし)。ローカル起動・ホスティングのどちらでも同じものを使う
- `public/index.html` — 部下管理・1on1準備・1on1後記録・履歴/傾向の4画面を持つフロントエンド
- `state/subordinates.json` — 部下プロフィール
- `state/logs.json` — 1on1ログ(直近1000件まで保持)
