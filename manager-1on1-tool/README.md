# 1on1支援ツール(フェーズ3)

「新任管理職になったが、1on1で何を話せばいいか分からない」という悩みを解決するためのツールです。
部下プロフィールを登録しておくと、Claude APIが1on1前のアジェンダ案を提案し、1on1後は生のメモから要点・判断基準・次回フォローを抽出して記録します。複数回の記録が溜まると、評価面談や異動判断の材料になる傾向サマリーも生成できます。

## 設計のポイント

- **直属部下と委任先チームリーダーでテンプレートを分ける** — 直属部下には成長・意思決定の拠り所を、委任先チームリーダーには委任範囲の進捗と判断基準のズレ確認を重視した観点でアジェンダを作ります。
- **感想ではなく判断基準を記録する** — 1on1後の記録では「良い感じだった」のような感想ではなく、「何を根拠にどう判断したか」を`judgmentCriteria`として言語化する設計にしています。属人化した勘ではなく、原理原則に基づいた振り返りを積み上げることが目的です。

使い方は2通りあります。

- **A. GitHub Issue + Discord通知(スマホだけで完結・推奨)** — PC不要、サーバーも自分で立てない
- **B. ローカルWebアプリ** — PCで `npm start` して、ブラウザの画面から使う

---

## A. GitHub Issue + Discord通知(スマホだけで完結)

スマホのブラウザ(またはGitHubアプリ)からこのリポジトリに **Issueを1件作るだけ** で、部下登録・1on1準備・1on1後記録・傾向分析のすべてが行えます。結果はそのIssueへの返信コメントとDiscordの両方に届きます。

### セットアップ(最初の1回だけ)

すでに `comment-generator` 用に登録済みなら追加設定は不要です。未設定の場合はリポジトリの
Settings → Secrets and variables → Actions で以下を登録してください。

- `ANTHROPIC_API_KEY`: Claude APIキー
- `DISCORD_WEBHOOK_URL`: 通知を受け取るDiscordチャンネルのWebhook URL

(`GITHUB_TOKEN` はGitHub Actionsが自動で発行するので登録不要です)

### 使い方

スマホでリポジトリを開き、「Issues」→「New issue」から、目的に合ったテンプレートを選んで送信してください。数十秒〜1分ほどでGitHub ActionsがClaude APIを呼び出し、結果がそのIssueへの返信コメントとDiscordに届きます。

1. **[1on1] 部下登録** — 最初に、話す相手(直属部下 or 委任先チームリーダー)を登録します。名前は以降の操作で「対象」として入力する表記の基準になるので、覚えやすい表記にしてください(例: `山田さん`)
2. **[1on1] 準備(アジェンダ生成)** — 「対象」に登録した名前、「直近の業務状況」に分かる範囲のメモを入力すると、優先度順のアジェンダ案(項目・なぜ今回扱うか・問いかけ例)が届きます
3. **[1on1] 後記録(要点抽出)** — 1on1が終わったら「対象」と「1on1メモ」(生のメモでOK)を入力すると、要点・判断基準・次回フォローに整理されて記録されます
4. **[1on1] 傾向分析** — 「対象」を入力すると、これまでの記録から変化の傾向をサマリー化します(評価面談・異動判断の材料に)

「対象」は部下登録時の「名前」と完全に一致する表記で入力してください。見つからない場合は、現在登録済みの名前一覧がIssueコメントで返信されます。

登録内容や記録は `state/subordinates.json` / `state/logs.json` としてリポジトリにコミットされ、次回以降のリクエストで参照されます。

### 関連ファイル

- `.github/ISSUE_TEMPLATE/1on1-register.yml` / `1on1-agenda.yml` / `1on1-log.yml` / `1on1-trend.yml` — 4つのIssue作成フォーム
- `.github/workflows/manager-1on1-tool.yml` — Issue作成(該当ラベル付き)をトリガーに起動するワークフロー
- `bot.js` — ワークフローから実行される本体スクリプト

## B. ローカルWebアプリ

```bash
cd manager-1on1-tool
ANTHROPIC_API_KEY=sk-ant-xxxx npm start
```

ブラウザで `http://127.0.0.1:3100` を開きます。

環境変数:

- `ANTHROPIC_API_KEY`(必須): Claude APIキー
- `PORT`(任意): 待受ポート。デフォルト `3100`
- `HOST`(任意): 待受ホスト。デフォルト `127.0.0.1`(自分のPC以外からアクセスされないようにするため)

### 画面構成

1. **部下管理** — 名前・役割・経験年数・関係(直属部下/委任先チームリーダー)を登録
2. **1on1準備** — 対象と直近の業務状況を入力すると、優先度順のアジェンダ案(項目・理由・問いかけ例)を生成
3. **1on1後記録** — 1on1メモを貼り付けると、要点・判断基準・次回フォローをAIが抽出して記録
4. **履歴・傾向** — 対象を選ぶと過去の記録一覧と、複数回の記録から見える変化の傾向サマリーを生成

---

## ファイル構成

- `lib/generate.js` — Claude APIでアジェンダ生成・要点抽出・傾向分析を行う共通処理(A・B共用)
- `lib/store.js` — 部下プロフィール・1on1ログの読み書き共通処理(A・B共用)
- `server.js` — ローカルWebアプリのAPIサーバー(B。Node標準ライブラリのみ、依存パッケージなし)
- `public/index.html` — 部下管理・1on1準備・1on1後記録・履歴/傾向の4画面を持つフロントエンド(B)
- `bot.js` — GitHub Actionsから実行されるIssue用の本体スクリプト(A)
- `state/subordinates.json` — 部下プロフィール(A・B共用)
- `state/logs.json` — 1on1ログ(直近1000件まで保持。A・B共用)
