# コメント自動生成(フェーズ2)

他の人のThreads(や他SNS)の投稿に返信コメントを書くのが面倒、という課題を解決するツールです。
コメントしたい投稿のURL(または本文)を渡すと、Claude APIが自然な返信コメント案を3パターン作成します。
**実際の投稿(送信)は行いません。** 生成された案をコピーして、手動で貼り付けて投稿する運用です。

使い方は2通りあります。

- **A. GitHub Issue + Discord通知(スマホだけで完結・推奨)** — PC不要、サーバーも自分で立てない
- **B. ローカルWebアプリ** — PCで `npm start` して、ブラウザのフォームから使う

## なぜ全自動で投稿しないのか

ThreadsをはじめSNSの公式APIは基本的に「自分のアカウントの投稿・返信」を対象としており、任意の他人の投稿を機械的に取得してコメントを自動送信する仕組みは想定されていません。また、内容を確認せず自動でコメントを送り続けると、スパム的な挙動としてプラットフォームの検知対象になり得ます。そのため、このツールは「投稿を調べてコメント文を考える」面倒な部分だけを自動化し、投稿するかどうかの最終判断は人間に残す設計にしています。

## A. GitHub Issue + Discord通知(スマホだけで完結)

コメントしたい投稿を見つけたら、スマホのブラウザ(またはGitHubアプリ)からこのリポジトリに **Issueを1件作るだけ** で、自動でコメント案がDiscordに届きます。

### セットアップ(最初の1回だけ)

すでに `threads-post-generator` 用に登録済みなら追加設定は不要です。未設定の場合はリポジトリの
Settings → Secrets and variables → Actions で以下を登録してください。

- `ANTHROPIC_API_KEY`: Claude APIキー
- `DISCORD_WEBHOOK_URL`: 通知を受け取るDiscordチャンネルのWebhook URL

(`GITHUB_TOKEN` はGitHub Actionsが自動で発行するので登録不要です)

### 使い方

1. スマホでリポジトリを開き、「Issues」→「New issue」→ 「コメント案リクエスト」テンプレートを選ぶ
2. 分かる範囲で入力して送信する
   - **投稿URL** がわかれば、それだけでOK(自動で本文の取得を試みます)
   - 自動取得できない投稿も多いので、確実なのは **投稿本文をそのまま貼り付ける** ことです(コピペでOK)
   - テンプレートを使わず、Issue本文にURLか投稿文をそのまま貼り付けるだけでも動きます
3. 数十秒〜1分ほどでGitHub ActionsがClaude APIを呼び出し、コメント案3パターンをそのIssueへの返信コメントとDiscordの両方に投稿します
4. 気に入った案をコピーして、Threadsアプリから **自分で** 投稿する

投稿URLからの自動取得は、投稿ページに埋め込まれた公開のリンクプレビュー用情報(OGP)を読みに行くベストエフォートの仕組みです。ログインが必要なページや非対応の形式では失敗することがあり、その場合はIssueのコメントで「本文を直接貼り付けてください」と案内されます。

### 関連ファイル

- `.github/ISSUE_TEMPLATE/comment-request.yml` — Issue作成フォーム
- `.github/workflows/comment-request.yml` — Issue作成をトリガーに起動するワークフロー
- `bot.js` — ワークフローから実行される本体スクリプト
- `lib/fetchPost.js` — 投稿URLからOGPを取得するベストエフォートの本文取得処理

## B. ローカルWebアプリ

```bash
cd comment-generator
ANTHROPIC_API_KEY=sk-ant-xxxx npm start
```

ブラウザで `http://127.0.0.1:3000` を開きます。

環境変数:

- `ANTHROPIC_API_KEY`(必須): Claude APIキー
- `PORT`(任意): 待受ポート。デフォルト `3000`
- `HOST`(任意): 待受ホスト。デフォルト `127.0.0.1`(自分のPC以外からアクセスされないようにするため)

### 使い方

1. コメントしたい投稿の本文を「相手の投稿内容」に貼り付ける
2. 投稿者名・投稿URLは任意(メモ用。URLは自動では使用されません)
3. 「普段のトーン」は初回だけ入力すればブラウザに保存され、次回以降は自動で入ります
4. 必要なら「追加の指示・文脈」に一言添える(例: 親しい同業者なので少しフランクに)
5. 「コメント案を生成する」を押すと3パターン表示される
6. 気に入ったものを「コピー」でクリップボードにコピーし、Threads側に手動で貼り付けて投稿
7. 投稿したら「投稿した(履歴に記録)」を押しておくと、次回以降の生成時に同じ言い回しを避けるための参考データとして使われる

## ファイル構成

- `lib/generate.js` — Claude APIでコメント案を3パターン生成する共通処理(A・B共用)
- `lib/history.js` — 履歴の読み書き共通処理(A・B共用)
- `lib/fetchPost.js` — 投稿URLからOGPを取得するベストエフォートの本文取得処理(Aで使用)
- `server.js` — ローカルWebアプリのAPIサーバー(B。Node標準ライブラリのみ、依存パッケージなし)
- `public/index.html` — Webアプリの入力フォームと結果表示画面(B)
- `bot.js` — GitHub Actionsから実行されるIssue用の本体スクリプト(A)
- `state/history.json` — 生成・使用したコメントの履歴(直近200件まで保持し、生成時に重複表現を避けるために使う。A・B共用)
