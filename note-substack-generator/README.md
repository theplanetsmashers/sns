# note→Substack導入記事生成

英語圏の読者にnoteの記事を届けるためのツールです。noteには2026年5月から記事タイトル・本文を自動で英訳する機能があり、
`?hl=en` を末尾に付けたURLで英語版として読めます。ただしその翻訳版に英語圏の読者を呼び込む導線(Substackなど)が別途必要になるため、
このツールはSubstackに投稿する「導入記事(ティザー記事)」を英文で自動生成します。

**実際にSubstackへ投稿するのは人間です。** 生成された記事はこの画面上でコピーするだけで、投稿(公開)は必ず自分の判断で行ってください。

## 使い方

```bash
cd note-substack-generator
ANTHROPIC_API_KEY=sk-ant-xxxx npm start
```

ブラウザで `http://127.0.0.1:3001` を開きます。

環境変数:

- `ANTHROPIC_API_KEY`(必須): Claude APIキー
- `PORT`(任意): 待受ポート。デフォルト `3001`
- `HOST`(任意): 待受ホスト。デフォルト `127.0.0.1`(自分のPC以外からアクセスされないようにするため)

### 手順

1. 紹介したいnote記事の本文をコピーして「note記事の本文(日本語)」に貼り付ける
2. 記事のURLがあれば「note記事のURL」に入力する(`?hl=en` を付けた英語自動翻訳版へのリンクが、生成される記事内に自然な形で案内されます)
3. 必要なら文体・トーンや追加の指示を入力する(初回だけ入力すればトーンはブラウザに保存されます)
4. 「Substack導入記事を生成する」を押すと、英語の導入記事が1本生成される
5. 「コピー」でクリップボードにコピーし、Substackの下書きに貼り付けて内容を確認のうえ、自分で公開する

生成される記事は元記事の逐語訳ではなく、海外読者向けに文脈を補いながら興味を引く導入(400〜600語程度)で、
最後にnoteの英語翻訳版(または元記事URL)への案内が入るように作られています。

## ファイル構成

- `lib/generate.js` — Claude APIでSubstack導入記事を生成する処理
- `server.js` — ローカルWebアプリのAPIサーバー(Node標準ライブラリのみ、依存パッケージなし)
- `public/index.html` — Webアプリの入力フォームと結果表示画面
