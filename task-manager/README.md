# タスク管理ツール

ブラウザだけで動くシンプルなタスク管理アプリです。サーバー不要、データはブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで直接開くか、任意の静的サーバーで配信してください。

```bash
cd task-manager
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 機能

- 右上の「＋」ボタンをタップすると入力フォームが吹き出しで表示される(ワンタップ操作、それ以外は常時非表示)
- タスクの追加・削除、編集(✏️ボタンでタスク名・期限日・時刻をまとめて編集)
- 完了/未完了の切り替え
- 優先度(高・中・低)、区分(仕事・私用)、カテゴリ、期限日の設定
- 期限日には任意で時刻まで指定可能(時刻ありの場合はその時刻を過ぎると期限超過扱い)
- 期限日を設定すると「繰り返し」(なし・毎週・毎月)を選択可能。繰り返し設定したタスクを完了チェックすると、削除されずに次回の期限(毎週なら+7日、毎月なら翌月の同日・月末は自動調整)へ自動的に更新される
- 期限超過タスクの自動ハイライト
- ステータス(すべて/未完了/完了)・区分(すべて/仕事/私用)のフィルタと並び替え(作成日順/期限順/優先度順)・検索欄をプルダウン/入力欄で横一列に表示
- ドラッグ&ドロップによる手動並び替え
- ネオングロー・ダーク基調のUI(シアン/マゼンタの発光アクセント、期限超過タスクはカード左端がマゼンタに光る)
- ブラウザの `localStorage` によるデータ永続化
- 📤エクスポート/📥インポートボタンでタスクをJSONファイルとして書き出し・読み込み可能(別端末にファイルを送って読み込めば手動で同期できる。インポートすると現在のタスクは置き換えられる点に注意)
- 🔗ボタンから「同期コード」を発行/入力することで、複数端末間でタスクを自動同期できる(詳細は下記)

## 端末間の同期について

ヘッダーの🔗ボタンから同期機能を利用できます。

- 「新しい同期コードを発行」を押すと8桁のコード(例: `A3F9K2QZ`)が発行されます。
- 別の端末で同じ🔗ボタンからそのコードを入力して「接続」すると、以後その端末同士でタスクが自動的に共有されます(4秒ごとに同期を確認)。
- 同期は「最後に保存した端末の内容で全体が上書きされる」方式です。同時に別々の端末で編集すると、後から保存した方が優先されます。
- 同期を使わない場合は今まで通り `localStorage` のみで動作し、他の端末とは共有されません。
- 同期コードを知っている人であれば誰でもそのデータにアクセスできます(パスワードではないため、コードは信頼できる相手とだけ共有してください)。

この同期機能は無料のFirebase(Firestore)を利用しており、`index.html`/`app.js` および配布用の `dist/task-manager-standalone.html` のどちらでも同じように使えます(アカウント登録やサインインは不要)。

同じ内容を公開している Claude の Artifact ページは、これとは別に Artifact 基盤の共有データベース機能を使ったリアルタイム同期を備えています(Claudeへのサインインが前提のため、note経由でファイルを配布する購入者などには使えません)。通常は🔗ボタンの同期機能で十分です。

## note特典などでの配布について

`dist/task-manager-standalone.html` は、CSS・JSをすべて1つのHTMLファイルに統合した配布用ファイルです。サーバーやアカウントは不要で、ダウンロードした人がダブルクリックしてブラウザで開くだけで使えます(データは各自のブラウザの `localStorage` に保存され、他の人とは共有されません)。🔗ボタンの同期機能もこのファイル単体で動作します。noteの有料記事などに特典として添付する場合は、このファイルをそのまま配布してください。
