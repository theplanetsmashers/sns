# タスク管理ツール

ブラウザだけで動くシンプルなタスク管理アプリです。サーバー不要、データはブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで直接開くか、任意の静的サーバーで配信してください。

```bash
cd task-manager
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 機能

- 右上の「＋」ボタンをタップすると入力フォームが吹き出しで表示される（ワンタップ操作、それ以外は常時非表示）
- タスクの追加・削除、編集（✏️ボタンでタスク名・期限日・時刻をまとめて編集）
- 完了/未完了の切り替え
- 優先度（高・中・低）、区分（仕事・私用）、カテゴリ、期限日の設定
- 期限日には任意で時刻まで指定可能（時刻ありの場合はその時刻を過ぎると期限超過扱い）
- 期限日を設定すると「繰り返し」（なし・毎週・毎月）を選択可能。繰り返し設定したタスクを完了チェックすると、削除されずに次回の期限（毎週なら+7日、毎月なら翌月の同日・月末は自動調整）へ自動的に更新される
- 期限超過タスクの自動ハイライト
- ステータス（すべて/未完了/完了）・区分（すべて/仕事/私用）のフィルタと並び替え（作成日順/期限順/優先度順）・検索欄をプルダウン/入力欄で横一列に表示
- ドラッグ&ドロップによる手動並び替え
- ネオングロー・ダーク基調のUI（シアン/マゼンタの発光アクセント、期限超過タスクはカード左端がマゼンタに光る）
- ブラウザの `localStorage` によるデータ永続化
- 📤エクスポート/📥インポートボタンでタスクをJSONファイルとして書き出し・読み込み可能（別端末にファイルを送って読み込めば手動で同期できる。インポートすると現在のタスクは置き換えられる点に注意）

## 端末間の同期について

このリポジトリの `index.html`/`app.js`（および配布用の `dist/task-manager-standalone.html`）はサーバーを持たない静的ファイルなので、データは開いたブラウザの `localStorage` にのみ保存されます（他の端末・ブラウザとは自動では共有されません）。複数端末で使う場合は、📤エクスポートで書き出したJSONファイルをLINE/AirDrop/メールなどで別端末に送り、📥インポートで読み込んでください（自動同期ではなく手動での一括反映です）。

同じ内容を公開している Claude の Artifact ページは、Artifact 基盤の共有データベース機能を使ってタスクをリアルタイム自動同期しており、同じリンクをスマホ・PC など複数端末で開けば同じタスク一覧が自動で共有されます（Claudeへのサインインが前提のため、note経由でファイルを配布する購入者などには使えません）。自分用にリアルタイム同期を使いたい場合は、ローカルの `index.html` ではなく公開済みの Artifact リンクを利用してください。

## note特典などでの配布について

`dist/task-manager-standalone.html` は、CSS・JSをすべて1つのHTMLファイルに統合した配布用ファイルです。サーバーやアカウントは不要で、ダウンロードした人がダブルクリックしてブラウザで開くだけで使えます（データは各自のブラウザの `localStorage` に保存され、他の人とは共有されません）。noteの有料記事などに特典として添付する場合は、このファイルをそのまま配布してください。
