# タスク管理ツール

ブラウザだけで動くシンプルなタスク管理アプリです。サーバー不要、データはブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで直接開くか、任意の静的サーバーで配信してください。

```bash
cd task-manager
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 機能

- タスクの追加・編集（タイトルをクリック）・削除
- 完了/未完了の切り替え
- 優先度（高・中・低）、カテゴリ、期限日の設定
- 期限超過タスクの自動ハイライト
- ステータス（すべて/未完了/完了）でのフィルタ
- タイトル・カテゴリでの検索
- 作成日順・期限順・優先度順の並び替え
- ドラッグ&ドロップによる手動並び替え
- ライト/ダークテーマ切り替え
- ブラウザの `localStorage` によるデータ永続化
